Privacy Policy

Last updated: November 5, 2026

Hermes Personal is a private tool used only by its owner, Jack Kirchner, with his own Google account.

What it accesses

With the owner's permission, it reads and manages the owner's Gmail, Google Calendar and Google Drive data so it can sort, summarize and file that information for him.

How data is used and stored

  • Data is used only to do tasks the owner asks for.
  • Data stays on the owner's own computer and Google account. It is not sold, shared or used for advertising.
  • Google user data is handled in line with the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
